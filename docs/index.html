Samlight Kodi Repository

Personal repository. Hosts plugin.video.samlight.

  1. In Kodi: Settings → System → Add-ons → enable Unknown sources.
  2. Download the repository zip.
  3. Add-ons → Install from zip file → select that zip.
  4. Add-ons → Install from repository → Samlight Repository → Video add-ons → Sam Light.

Kodi then checks this address on its own and updates the addon when a new build is published.
